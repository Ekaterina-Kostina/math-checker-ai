# math-checker-ai
HSE team project
## Project Overview

**Math Checker AI** is a deep learning prototype for recognizing and digitizing handwritten math solutions from students.  
The goal is to reduce teachers’ manual workload in grading and speed up feedback delivery.

---

## Goal

Build an MVP that:
- accepts an image with a handwritten math solution  
- recognizes text and mathematical formulas
- outputs a clean digital version of the solution

Future versions may include:
- automatic error detection  
- reasoning analysis  
- feedback generation via LLMs
